# The World in One Day — Tuesday 24 November 2026

A make.fun entry for [news-image-20261124](https://make.fun/bounty/news-image-20261124): a program that draws one 1024x1024 image summing up Tuesday 24 November 2026 world news. A large dotted world map with 35 numbered story markers sits above the 35 stories grouped by region — North America, Latin America, Europe, Africa, Middle East, Asia, and Oceania & Pacific.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024 PNG, under 1 MiB). The program uses only the Python standard library, makes no network calls, and writes byte-identical output on every run.

## Stories covered

35 stories reported on 24 November 2026, including the COP31 climate summit collapsing with no deal, Nvidia shares jumping a third as Jensen Huang returns as CEO, FIFA confirming the 2031 and 2035 Women's World Cup hosts, Russian strikes on Ukraine's Kyiv region, the Indonesia factory fire, Alcaraz winning a maiden ATP Finals title, and Gukesh beginning his world chess title defence.
